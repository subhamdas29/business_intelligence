# AI Business Intelligence SaaS Platform ("AI Data Analyst")

An enterprise-grade, multi-tenant AI Data Analyst platform that ingests CSV/Excel datasets and unstructured documents, automatically profiles data quality, extracts metrics/KPIs, generates dashboard visualizations, detects trends/anomalies, and provides a safe, deterministic natural-language AI query engine with total mathematical truthfulness and provenance.

---

## Key Features & Core Principles

1. **Deterministic Numerical Truth**: All calculations, KPIs, and chart data are powered by SQL database queries or deterministic analytical code (Pandas/Polars/SciPy). The LLM is used strictly for intent classification, query planning, explanation, and natural language communication.
2. **AI Safety Pipeline**: 11-stage query execution and validation pipeline. SQL generated by AI is parsed into ASTs, verified against schemas and strict allowlists, and executed strictly over read-only database connections. Arbitrary execution of untrusted code or destructive SQL (`DROP`, `DELETE`, `UPDATE`, `INSERT`) is strictly blocked.
3. **Strict Multi-Tenancy & RBAC**: Organization-level isolation enforced at both DB schema and API layers. Role-based access control with `OWNER`, `ADMIN`, `ANALYST`, and `VIEWER` roles.
4. **Automated Analytics & Dashboards**: Automated dataset profiling, schema inference, data quality reports, anomaly detection, statistical summary, and auto-generated visualization widgets (line, bar, scatter, pie, map).
5. **Hybrid Analytics (Data + RAG)**: Seamlessly combines structured database queries with pgvector-backed semantic document retrieval with precise citations.
6. **Auditability & Provenance**: Every AI-generated response exposes full provenance—including exact SQL queries, execution timings, underlying charts, source datasets, and confidence ratings.

## Quick Start (Local Development)

### Prerequisites
- [Docker](https://www.docker.com/) & Docker Compose
- [Python 3.11+](https://www.python.org/)
- [Node.js 18+](https://nodejs.org/)

### Running with Docker Compose

1. Clone the repository and copy the environment file:
   ```bash
   cp .env.example .env
   ```
2. Build and launch all services:
   ```bash
   docker-compose up --build
   ```
3. Access the services:
   - **Frontend UI**: `http://localhost:3000`
   - **FastAPI API Documentation**: `http://localhost:8000/docs`
   - **PostgreSQL Database**: `localhost:5432`
   - **Redis**: `localhost:6379`
